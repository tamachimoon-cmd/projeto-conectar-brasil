# Comandos de produção — Conectando o Brasil

## Comando: REGISTRA NO GIT

Quando o usuário disser **“registra no git”** após revisar um take, isso significa que o take foi **APROVADO**.

Ao receber esse comando:

1. Considerar a versão atual do take como versão oficial aprovada.
2. Registrar no GitHub todos os detalhes consolidados daquele take:
   - número e título;
   - duração;
   - personagens;
   - divisão temporal segundo a segundo;
   - cenário e referências geográficas;
   - ações;
   - enquadramentos e movimentos de câmera;
   - identidade visual;
   - iluminação;
   - efeitos e conexão púrpura;
   - textos destinados à pós-produção;
   - transição de entrada;
   - transição para o take seguinte;
   - prompt final de produção para Google Flow;
   - restrições e elementos que não devem aparecer.
3. Não alterar posteriormente um take aprovado sem uma nova solicitação explícita do usuário.
4. O take aprovado passa a ser a referência de continuidade para a criação do take seguinte.
5. Antes de desenvolver o próximo take, consultar a versão registrada quando necessário para preservar continuidade visual e narrativa.

## Comando: STOP

Quando o usuário disser **“Stop”**, consultar o estado atual do projeto no GitHub antes de continuar, usando o repositório como fonte de verdade.
